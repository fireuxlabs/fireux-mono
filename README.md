# FireUX Mono

FireUX is a Nuxt-based SaaS framework that integrates Nuxt UI and Firebase.
This workspace contains the framework, reusable capabilities and concrete Apps.

- [FireUX Core](packages/core/fireux-core/README.md) provides the shared framework.
- [Packages](packages/README.md) maps Core, Extensions and Ecosystems.
- [Projects](projects/) contains concrete Apps and the starter.
- [Development tools](tools/) contains local workflows and release tooling.

Use [AGENTS.md](AGENTS.md) for working rules. See the
[repository architecture](docs/concepts/fireux-mono.md) for package relationships
and [current priorities](docs/roadmaps/fireux-priorities.md) for planning.
Building an App? See the [FireUX developer guide](https://fireux.app/getting-started).
