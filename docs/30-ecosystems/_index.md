# Ecosystem Documentation Overview

The FireUX ecosystem packages share a consistent set of guidance docs hosted under `packages/ecosystem/*/docs/`. Use this section to understand where each package keeps its canonical references.

- `packages/ecosystem/fireux-cleanbox/docs/` — tenant operations and product narrative
- `packages/ecosystem/fireux-fireux/docs/` — core FireUX product positioning and roadmap
- `packages/ecosystem/fireux-misebox/docs/` — Misebox-specific objectives, research, and plans
- Each ecosystem folder includes `mission.md`, `liturature.md`, `gap.md`, and `roadmap.md` as the current working set
- Promote stable guidance into `docs/` when it becomes cross-ecosystem canonical material
