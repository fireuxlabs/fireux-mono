# Cleanbox Ecosystem

## Mission

Encapsulate the cleaning-industry defaults—branding, copy, job types, and operational hooks—built on FIReUX, while leaving service, rota, and checklist models open for each deployment to define.

## Purpose

- Supply the Cleanbox visual identity and language.
- Establish cleaning-domain taxonomies (office cleans, end-of-tenancy, housekeeping, construction, etc.).
- Offer extension points for:
  - checklists and quality audits,
  - schedules and rota planning,
  - client or site records.
- Mirror the FIReUX philosophy: keep entities pluggable, never hard-coded, so every tenant can tailor its operations.
