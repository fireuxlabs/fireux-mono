# FireUX Documentation

Canonical framework docs live at `docs/` in the monorepo root.

- Human-facing framework docs: `docs/`
- Archived notes and temporary reports: `docs/90-appendices/archive/`
- Ecosystem/app docs: keep them local (e.g., `packages/**/docs/`, `projects/**/docs/`)
- Agent/internal handbook: `copilot-documentation/`
- AI control prompts: `.github/prompts/`

If you are looking at a Markdown file outside these locations, consider moving it into the canonical docs or archive.
