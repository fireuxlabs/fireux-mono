# Card roles

Updated: 2026-11-22
Ref: 0d8d59ce8
Role: map, not canon

Use these names if they help a consumer describe its presentation:

- **Pill** displays compact identity or selection.
- **Cell** displays one record in a list.
- **Preview** displays supplied data for review.
- **Overview** displays a richer account of an Entity.

A domain chooses the roles its consumers need. Supply data and authorized
actions from the owning reader or controller. Navigation uses a link, actions
use buttons, and a passive card remains noninteractive. Cards own presentation
and do not silently fetch, join or write records.
