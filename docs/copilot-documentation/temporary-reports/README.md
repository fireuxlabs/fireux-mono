# Temporary Reports

This folder is for short-lived notes, investigations, and drafts that are useful during active work but should not become permanent canon.

## Rules

- Use `status: working` in frontmatter.
- Prefer linking to the relevant handbook chapter or ADR instead of duplicating canon.
- When something stabilizes:
  - Promote it into the correct handbook chapter (`docs/copilot-documentation/`) or an appendix (`docs/copilot-documentation/copilot-appendices/`).
  - Or move it into `docs/copilot-documentation/imported/` if it’s purely historical reference.

## Naming

Use a date prefix to keep things sortable: `YYYY-MM-<topic>.md`.
