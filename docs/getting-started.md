# Getting Started

Follow these steps to run FireUX locally and browse docs at `/docs`.

## Prerequisites

- Node 18+
- `pnpm` installed globally (`npm i -g pnpm`)

## Install dependencies

```sh
pnpm install
```

## Run the FireUX app (with docs)

```sh
pnpm dev:fireux
```

- Open http://localhost:3000/docs to view this documentation via Nuxt Content.
