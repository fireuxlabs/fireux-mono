# Guides
Authority: Tier2 (Operational)

Practical how-tos for working with FireUX. Start with these:

- New app creation system: `new-app.creation.md`
- Run/configure existing apps: `creating-apps.md`
- Work with profiles: `profiles.md`

For any new deployable app, start with `new-app.creation.md`. Do not begin app-local pages, styling, data wiring, or product features until the pre-dev gate in that guide is complete or explicitly marked blocked.
