## Discrepancies and next decision

- Alpha 8 correctly separates identity and ownership. Source establishes historical consumers for the two Ecosystem keys, the Project provisioning input, the private context seed, and the Jobs registries. They have historical responsibilities even though the current public pipeline requires none of those legacy keys.
- Alpha 7's suggested metadata destination for `homePath` has no current requirement. The old sitemap paths served publication, and a future prerender list is a separate behavior.
- Existing App fields cover the minimum metadata. The missing contract support is Ecosystem-free standalone acquisition. The model and projector still require `ecosystem_id`, and current scoped operations depend on private `fireux.ecosystemId`. Decide the trusted self boundary and absent membership representation before changing those paths.
- The old config is already out of the reset App. There is nothing to bulk-delete from its native config for the discussed keys. After authorization, the smallest presentation slice is to drive Misebox's heading and Detail from the existing single SSR result. Keep bounded peer reads and verify failure states in Blank and Misebox. Review each returning feature separately.
