# Shared foundation acceptance

Reviewed: 2026-10-28
Scope: Project/Kitchen Identity and the Apps collection chain
Role: dated local evidence, not platform-wide or release certification

The bounded foundation slice is locally accepted. Both reference Identity pages
use the persistent Core Workspace frame, breadcrumbs and navigation. Shared
profile layout belongs to Core's existing `workspace-profiles.scss`; Project
identity/publication and Kitchen's Place profile/listing retain their domain

Nuxt UI page components, shared state/pagination and the App collection. Core
reads the configured Ecosystem; the FireUX override reads the platform and owns
its distinct SEO. `useCollectionPage` supplies presentation over the existing
reader; `useAppCollectionPage` owns App acquisition and SEO. No custom page
wrapper, duplicate reader or live HTTP bridge was added.

the cross-Ecosystem directory; Misebox displayed its six Ecosystem Apps.

acceptance. Preimages and logs are retained outside the checkout. Unrelated
