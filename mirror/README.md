# Mirror

`mirror/` is a *flat*, generated workspace of symlinks for the files you want to keep “in view” during a task.

## Quick use

1. Edit `mirror/mirror.txt` (add/remove paths).
2. Regenerate: `node scripts/mirror-sync.mjs`.
3. Work from the symlinks in `mirror/` (but edit the real sources under `packages/**`).

## Rules (the “mirror contract”)

- **Source of truth:** `mirror/mirror.txt`.
- **Generated output:** everything in `mirror/` *except* `mirror/README.md` and `mirror/mirror.txt`.
- **Safe to delete:** generated symlinks only. Don’t delete the README or list file as part of normal workflow.
- **Flat only:** no subfolders under `mirror/` (symlinks must live in the `mirror/` root).
- **Never hand-edit symlinks:** don’t create/rename/delete symlinks manually; run the sync script instead.


## What goes in `mirror/mirror.txt`

- One repo-relative path per line.
- You can list a file or a directory.
	- If you list a directory, the sync script will include files under it (recursively).
- Lines starting with `#` are comments.
- **To set a custom symlink name:** add `# your-name.ts` after the path. Example:

			packages/core/fireux-core/src/runtime/composables/fireux/firestore/core/app/utils/view/useAppInterface.ts # app-interface.ts

	This will create a symlink named `app-interface.ts` in `mirror/`.

# Mirror (quick)

Purpose: a simple, flat workspace of symlinks for files you want to "peek" during work.

Quick commands
- Reset the mirror (remove symlinks + clear the list):

```sh
find mirror -type l ! -name 'README.md' ! -name 'mirror.txt' -delete && \
awk '/^[[:space:]]*#/ || /^[[:space:]]*$/ {print}' mirror/mirror.txt > mirror/mirror.txt.tmp && mv mirror/mirror.txt.tmp mirror/mirror.txt
```

- Generate symlinks from the list:

```sh
node scripts/mirror-sync.mjs
```

How to use
- Edit `mirror/mirror.txt`: add one repo-relative path per line (files or directories).
- Run `node scripts/mirror-sync.mjs` to populate `mirror/`.
- Work from the symlinks in `mirror/`; edit the original files in-place in the repo.

Mirror rules
- `mirror/mirror.txt` is the single source-of-truth (one path per non-comment line).
- Lines starting with `#` are comments.
- On reset, the filepaths (non-comment lines) are removed — only header/comments remain.
- To set a custom symlink name, append `# custom-name.ext` to a path on the same line.

Alignment notes (Company + Kitchen overlays)
- Company/Kitchen documents are overlays bound to a Place id.
- Overlay docs must include the shared place snapshot fields:
	id, name, formatted_address, lat, lng, place_image, search_term, search_term_normalized.
- Overlay docs may add domain fields, but no optionals (empty string = unset).
- Create/System must create from Place confirmation with a minimal write.

Examples
- Add a file:

```
packages/extensions/fireux-places/src/runtime/models/objects/place.model.ts
```

- Add a file with a custom symlink name:

```
packages/core/fireux-core/src/runtime/composables/useAppInterface.ts # app-interface.ts
```

That's it — keep `mirror/mirror.txt` as the list of paths you want visible, and use the reset command when you want a fresh starting point.
