# fireux-docs

Authority: Tier2 (Overview; package hierarchy canon in `docs/fireux-canon.md`)
Updated: 2026-06-12

Passive FireUX documentation module.

## Purpose

`fireux-docs` exposes documentation routes and reusable docs content for FireUX runtime concepts.

It is not the `Document` entity stack.
Uploaded files, document vault records, and document links belong to `fireux-documents`.

## Owns

- docs runtime pages
- docs layout/content helpers
- runtime concept documentation
- passive documentation navigation

## Does Not Own

- Portfolio document records
- uploaded file storage
- document links
- document workflow operations

## Related Package

Use `fireux-documents` for document vault/domain behavior.
