# fireux-cleanbox

Cleanbox ecosystem package for FireUX.

This package defines Cleanbox branding, configuration, and ecosystem-specific wiring used by apps in the Cleanbox ecosystem.

## Structure Authority

Package-root and `src/` structure for FireUX modules are defined centrally in:
- `packages/core/fireux-docs/README.md`
- `packages/core/fireux-docs/src/README.md`
