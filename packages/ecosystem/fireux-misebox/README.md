# fireux-misebox

Misebox ecosystem package for FireUX.

This package defines Misebox branding, configuration, and ecosystem-specific wiring used by apps in the Misebox ecosystem.

## Structure Authority

Package-root and `src/` structure for FireUX modules are defined centrally in:
- `packages/core/fireux-docs/README.md`
- `packages/core/fireux-docs/src/README.md`
