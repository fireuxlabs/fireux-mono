## Tenant Layout

Misebox tenant apps can use the `misebox-tenant` layout for the
out-of-the-box public landing surface. The ecosystem owns the frame and its
`components/layouts/misebox-tenant` header/footer parts. The tenant app owns
its brand media, palette tokens, and page content.
