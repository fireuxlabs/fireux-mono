# fireux-slap

Authority: Tier1 (package canon)
Updated: 2026-05-30

Slap is a FireUX-powered lifestyle-commerce ecosystem for culture-led brands.

FireUX remains the runtime, Firebase, deployment, SEO, product, blog, and console engine. Slap owns the public-facing brand wrapper, visual direction, ecosystem language, and lifestyle-commerce defaults.

## Boundary

- FireUX is the factory and serious operational layer.
- Slap is the sellable public-commerce surface: apps that slap, sites that sell.
- Slap projects can publish brand homepages, drops/products, stories, galleries, and optional service or tour pages.
- Yellow Velo is the first tenant identity in this ecosystem.

## Language

- FireUX Product -> Slap Drop or item
- FireUX Blog -> Slap Story
- FireUX Project -> Slap Brand
- FireUX Console -> Slap-backed FireUX console

## Apps

The global ecosystem app is `projects/slap/slap-app`.
The first tenant identity is `projects/slap/yellow-velo`.
