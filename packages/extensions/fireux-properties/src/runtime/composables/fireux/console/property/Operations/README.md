# Property Console Operations

This directory owns composables for work an operator does inside a selected Property workspace.

`operations` is a code bucket, not a Firestore collection, stored entity, or public route.

Use this layer for selected-Property work only when BuenoHost property console behavior is explicit.

Keep stored CRUD in `firestore/`.
Keep guest-facing route shaping in `public/property/`.
Keep demo scenario data in `demo/property/`.
