# Supplier Public Layer

This directory is reserved for guest-facing Supplier route helpers.

Supplier currently has:
- `firestore/supplier` for stored Supplier data
- `console/supplier` for selected Supplier operator workspace behavior
- `demo/supplier` for Supplier demo scenario data

Add public Supplier helpers here when `/suppliers/**` needs route-specific view or SEO shaping that does not belong in the stored Firestore stack.
