# FIReUX Reference Tenant Layer

## Mission

Act as the neutral reference tenant that exercises every core FIReUX capability—runtime config, theming, module wiring, and environment contracts—without introducing any business domain.

## Purpose

- Prove the tenant loader end-to-end.
- Demonstrate theming and branding hooks.
- Show modules can be toggled in or out safely.
- Stay intentionally boring: no hospitality, no cleaning, no production entities.

Use this tenant as the template for new ecosystems before applying domain flavour.
