# FireUX Projects

Authority: Wayfinding only
README role: Map only; not canon.
Updated: 2026-06-17

Projects are app workspaces.

Apps consume packages. Apps may own shell, config, content, assets, and app-local routes.
Apps do not redefine shared domain canon.

When a project needs shared runtime behavior, move the behavior into the owning core,
ecosystem, or extension package.
