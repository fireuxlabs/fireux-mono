# Cleanbox Global Shell

## Mission

Demonstrate the Cleanbox ecosystem in action: auth, scheduling glimpses, and tenant hand-off, while keeping industry specifics modular.

## Purpose

- Present the Cleanbox brand story and navigation.
- Exercise core flows (sign-in, onboarding, location selection) with hospitality-agnostic defaults.
- Showcase Cleanbox service listings without fixing the underlying data schemes.
- Provide a stable home for shared pages (marketing, help, account) that every Cleanbox tenant can rely on.
