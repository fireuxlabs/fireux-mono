# FireUX App

## Mission

Serve as the canonical global shell that boots the shared FIReUX UI, auth, and module pipeline, demonstrating how a multi-tenant SaaS can launch on FIReUX before any industry flavour is applied.

## Purpose

- Validate global authentication flows.
- Showcase tenant switching and base navigation.
- Provide the "hello world" SaaS example for the platform.
- Offer a safe place to inspect shared dashboards, layouts, and runtime config.
