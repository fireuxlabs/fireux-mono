no-fireux-embed-test

Plain website harness

This page has no FireUX runtime, no Nuxt app, and no Firebase client SDK. It exists to prove that hosted FireUX/provider tools can be used by a normal external website.

For local comparison, run pnpm dev:embed-harness and then start the provider shown by the local panel. To start everything at once, run pnpm dev:embed-tools.
