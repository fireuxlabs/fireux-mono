# Friiites landing draft direction

These rules apply to visual mockups used as temporary landing-scene scaffolds.

- Do not add a decorative circular `III` badge to the top-right of each scene.
- Use the `III` motif only on a real branded object, such as packaging, a
  projecting shop sign, a counter, or an intentionally approved transition
  element.
- Every `III` motif contains exactly three gold bars.
- Full wordmarks use the canonical Friiites asset rather than generated
  lettering.
- Decorative marks do not fill empty space; negative space is intentional.
- A flattened mock is a composition reference, not authority for routes,
  capabilities, claims, or final accessible copy.
