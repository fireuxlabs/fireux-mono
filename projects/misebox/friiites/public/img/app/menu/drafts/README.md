reference. `../scene-two-menu.webp` is its temporary flattened runtime
derivative.

The flattened scene is an approved visual-first scaffold, not the final scene
architecture. Rebuild it progressively with real DOM menu content, canonical
brand assets, and independent food artwork while preserving the existing
`menu` scene and background/content/foreground layer contract.

Generated branding is not authoritative. The current draft was corrected to
show exactly three gold bars; final branded surfaces must use the canonical
Friiites wordmark asset rather than generated lettering or symbols.
