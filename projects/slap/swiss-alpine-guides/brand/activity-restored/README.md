# Restored activity photographs

The client requested Photoshop-style restoration of the existing photographs.
These masters were enhanced with Creative Claw's Recraft Crisp upscaler from
the same published original photos. They are 4× photographic restorations,
not replacement scenes. AI-assisted enlargement reconstructs detail and is not
an exact reproduction of information missing from the source. Original masters
and hashes remain under `../activity-originals`.

`restoration.json` records each selected source job, durable output URL, asset ID,
dimensions and web export settings. Rejected experiments are not runtime assets.
The glacier source was re-encoded as a clean PNG before the authorised retry.

Runtime `public/img/activities/restored-v1` exports use Lanczos reduction and
WebP quality 92 / AVIF quality 70. No further sharpening is applied to the
restored masters. Native picture consumers choose small card variants or larger
header variants; image focus remains in the activity catalogue. The landing
mountain animation and poster retain their separate source and delivery family.
