# Alpine photographic concept

AI-generated for the mobile-first Swiss Alpine Guides prototype. Not documentary
photography of a particular tour, and not a replacement or edit of the previously
approved portrait/helicopter artwork, which was not supplied to this checkout.

`distance.png` is the full scene. `ridge.png` and `foreground.png` are transparent
layers derived with the image-generation tool for the App-local scroll composition.
The source frames share a portrait canvas. Runtime WebP exports are optimized for
mobile and desktop; alpha is preserved on the two foreground layers.

The footer identifies the imagery as generated. Review and replace with approved
operator imagery when supplied. No helicopter was invented from missing references.
