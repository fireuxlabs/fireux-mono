# Public img trees (per app)

Canonical layout per app: `public/img/app/` holds branding, `public/img/app/pwa/` holds PWA icons. No root fallbacks.

## fireux-app
```
projects/fireux/fireux-app/public/img/
└─ app/
   ├─ cover.png
   ├─ logo.png
   ├─ thumbnail.png
   ├─ wordmark-dark.png
   ├─ wordmark-light.png
   ├─ wordmark-light.svg
   └─ stack/
      ├─ firebase-black.png
      ├─ firebase-white.png
      ├─ github-black.png
      ├─ github-white.png
      ├─ nuxt-black.png
      ├─ nuxt-white.png
      ├─ pwa-black.png
      ├─ pwa-white.png
      ├─ stripe-black.png
      └─ stripe-white.png
      
   └─ pwa/
      ├─ icon-192.png
      └─ icon-512.png
```
